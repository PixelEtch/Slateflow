# Getting help

- **Something isn't working:** check [Troubleshooting](docs/TROUBLESHOOTING.md) first.
- **Bug:** open an issue with the bug report template. Attach the log from **Help > Open Log File** and include your macOS and Slateflow versions (**Slateflow > About Slateflow**).
- **Idea or feature request:** open an issue with the feature request template.
- **Security problem:** don't open a public issue. See [SECURITY.md](SECURITY.md).

Slateflow is maintained by one person in spare time, so replies can take a few days.
